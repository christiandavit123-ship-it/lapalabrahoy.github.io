# La Palabra Hoy

Blog noticial con la fuerza de la razón.

## Características

- 📰 Sistema completo de noticias por categorías
- ✏️ Panel de administración para editar noticias
- 💾 Almacenamiento local en el navegador
- 📱 Diseño responsive
- 🎨 Estilo profesional y moderno

## Categorías

- Política
- Economía
- Mundo
- Sociedad
- Deportes
- Cultura

## Uso

1. Abre la página en tu navegador
2. Haz clic en "Editar noticias" para gestionar contenido
3. Agrega, edita o elimina noticias según sea necesario
4. Los cambios se guardan localmente en tu navegador

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla
- LocalStorage para persistencia
